# OverTheWire Bandit — Key Takeaways

This repository documents my learning journey through OverTheWire's Bandit wargame, focusing on the key Linux and cybersecurity concepts I learn from each level.

> Note: OverTheWire asks players not to share solutions to the wargames. To respect this, This repository does not include the passwords and solution steps.

The purpose of this repository is to keep a concise record of the skills I develop while solving the challenges independently.
<br>


##  Topics Covered
- Linux & command line fundamentals
- File systems & permissions
- SSH & networking
- Users & groups
- File searching & manipulation
- Pipes & redirection
- Encoding & decoding
- Compression & archiving
- Shell concepts
- General cybersecurity fundamentals
