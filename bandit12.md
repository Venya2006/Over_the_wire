# Bandit Level 11 -> Level 12

## Level Goal
The password for the next level is stored in the file data.txt, where all lowercase (a-z) and uppercase (A-Z) letters have been rotated by 13 positions

## Key concepts learnt
1. `ROT13` is a substitution cipher where each letter in the English alphabet is replaced by the letter 13 positions ahead of it.
2. `tr`(translate) is a command that replaces characters from one set with characters from another set.
