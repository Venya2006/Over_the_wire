# Bandit Level 8 -> Level 9

## Level Goal
The password for the next level is stored in the file data.txt and is the only line of text that occurs only once.

## Key concepts learnt
1. `sort` command is used to print the lines of its input text files in a specified ordered sequence.By default it is in an ascending order. 
2. `uniq -u ` command removes duplicate lines from a file.
