# Bandit Level 5 -> Level 6

## Level Goal
The password for the next level is stored in a file somewhere under the inhere directory and has all of the following properties:

- human-readable
- 1033 bytes in size
- not executable

## Key concepts learnt
1. `find` command can locate files in a directory, more over we can filter our search using properties like size, readability and executability.
